# Season Ticket: launch checklist

For the owner to tick off on their own phone before sharing the game: https://jxstrr0.github.io/SeasonTicket/

Everything here was also checked by script in 7.7; this list is what only a real phone can confirm.

## First visit
- [ ] Open the link in a fresh tab (or a private tab). The purple Longlight card shows for under two seconds, then the title screen.
- [ ] Tap anywhere during the card: it skips.
- [ ] With graphics on Medium the 3D stadium fades in and turns slowly. With graphics Off you see the still picture.
- [ ] Paste the link into a chat app: the preview shows the stadium picture, the name and the tagline.

## New career
- [ ] Start a career: pick a club, change its name and colours, tap Start the career. The Start button is not hidden behind a tip.
- [ ] The welcome tip shows once. Tap Got it; it does not come back.
- [ ] Menu → Show tips again brings the tips back.

## A season
- [ ] Play to the first match day. Watch a few minutes in 2D, make a substitution, tap Skip to full time.
- [ ] Watch a match in 3D at Medium. It runs smoothly (Menu → Show the frame rate to see the number).
- [ ] Answer a visitor, a press conference and a deadline-day call.
- [ ] Play on to the end of the season: the Season review shows, its playoff bracket fits the screen, and Start the off-season works.

## Safety
- [ ] Menu → Save code copies a code. Paste it into Load a save code on the title screen (in a private tab) and the same career loads.
- [ ] Paste a different career's code into Load a save code: it asks before replacing yours, and the title screen then shows your old career as a Backup. Bring it back returns it.
- [ ] Close the tab mid-week and reopen: Continue picks up where you were.
- [ ] Add to Home Screen, open it from the icon, switch to airplane mode and open it again: the game still opens.
- [ ] After the next update, the "A new version is ready" banner shows; Reload brings the new version.

## Wording and credits
- [ ] Credits (title screen and Menu) lists Longlight Interactive, every asset and its licence.
- [ ] Menu → Report a problem opens the Longlight contact page.
- [ ] Nothing says "season break" where it should say "off-season", and no real club, player or place names appear.
